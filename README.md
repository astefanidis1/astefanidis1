## Featured work

### [The Oracle - Automotive Lap-Time Prediction](https://github.com/astefanidis1/Laguna-Seca-Lap-Time-Predictor)
Machine-learning system for predicting Laguna Seca lap times from vehicle performance data. Built with TensorFlow/Keras, Optuna, SHAP, feature engineering, residual analysis, and real-world benchmark validation.

### [RNK - Uncertainty-Aware Ranking System](https://github.com/astefanidis1/RNK-New)
Ranking application built around uncertainty-aware matchmaking, designed to prioritize informative comparisons and accelerate convergence. Includes Firebase-backed persistence and a web application layer.

### [HCPS - Historical Combat Performance Simulator](https://github.com/astefanidis1/HCPS-Combat-Ranking)
Probabilistic comparative-ranking framework combining trait-based scoring, LLM-assisted evaluation, Monte Carlo simulation, normalization, and audit loops.

### [GAIA Atlas](https://github.com/astefanidis1/gaia-pokemon-atlas)
A geospatial data and world-modeling project combining structured population records, geographic ranges, movement logic, validation tooling, and an interactive map-based product experience.
